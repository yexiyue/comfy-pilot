# 05 · Agent 循环与 LangGraph 编排
对应 M1。目标：控制自主决策发生在哪里。

## 知识与术语
**Node（节点）**执行一次逻辑并提出状态更新。
**Edge（边）**连接步骤；条件边根据状态选择路径。
**Reducer（合并规则）**定义多个状态更新怎样组合，不应随意覆盖并发结果。
**Tool calling（工具调用）**包含模型请求、参数校验、实际执行和结果回传。
**Observation（观察）**是工具返回或用户反馈。
**Stop condition（停止条件）**限制循环，如达到目标、需要用户、能力不足或预算耗尽。

## 在 ComfyPilot 中
整理简报 → 选择可用工作流 → 程序校验 → 提交生成 → 获取结果 → 等待反馈。只有需要判断的环节调用模型，查询外部任务和检查尺寸可以由普通程序完成。

长时间等待生成不应变成模型反复询问“完成了吗”。外部任务等待与模型推理循环是两种不同过程。

## 设计问题
模型决定停止后还需验证什么？参数错误是否允许修正一次？某个工具是否应该在当前阶段不可见？

## 常见误区
每个节点都必须调用 LLM；把复杂图当成更强智能；让模型无限修正同一错误。

## 学完的验收
解释正常成功、缺少能力、参数校验失败三条路径。每个分支都有明确下一步和停止条件。
