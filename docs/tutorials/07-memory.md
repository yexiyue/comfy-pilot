# 07 · 短期状态与长期记忆
对应 M2。目标：知道什么应该记、记多久、怎样更正。

## 知识与术语
**Short-term memory（短期记忆）**是当前会话或任务中的状态。
**Long-term memory（长期记忆）**跨会话保留有用信息。
**Episodic memory（事件记忆）**记录过去发生的创作及反馈。
**Semantic memory（事实记忆）**记录已确认偏好等事实。
**Procedural memory（程序性记忆）**记录完成任务的方法或规则。
**Namespace（命名空间）**隔离不同用户、项目或记忆类别。
**Memory write policy（记忆写入策略）**决定哪些内容可以持久化。
**Retrieval（检索）**不一定使用向量数据库，也可以按项目、标签和时间查找。

## 在 ComfyPilot 中
“这张封面用暖色”是当前任务约束；“我的博客一直用暖色和大留白”才可能成为跨项目偏好。应保存来源和确认状态，并支持修改、删除。

显式保存的品牌偏好优先于模糊推断；最新明确要求可以覆盖旧偏好。本地资产存在不意味着它应该跨项目进入模型上下文。

## 设计问题
什么时候询问是否记住？过时偏好怎样失效？同一用户两个风格完全不同的项目如何隔离？

## 常见误区
把全部聊天向量化就拥有了可靠记忆；检索结果自动成为权威事实；将一次拒绝泛化为永久喜好。

## 学完的验收
对十条用户反馈分类为任务状态、可保存偏好、事件记录或无需记忆；展示一次旧偏好被明确纠正后的行为变化。
