# 11 · 流式体验、画廊与迭代交互
对应 M4。目标：发挥前端经验，让系统状态可理解。

## 知识与术语
**Streaming（流式传输）**逐步发送消息或任务事件。
**SSE / WebSocket**是不同的事件通信方式；应用可以在服务端做协议转换。
**Event projection（事件到视图的映射）**把运行记录转成用户可理解的卡片和进度。
**Optimistic UI（乐观界面）**先呈现预期变化，但外部生成不能仅凭乐观状态宣称成功。
**Reconnect（重连）**恢复通信后还需要同步状态。
**Artifact-centric UI（围绕产物的界面）**让图片、选择和版本成为主要操作对象。

## 在 ComfyPilot 中
主区域展示候选图与版本对比，对话用于表达要求；任务卡区分等待执行、运行中、等待反馈、失败和结果未知。没有真实进度来源时，不显示虚构百分比。

开发视图展示本轮模型输入、工具和状态更新；用户界面主要展示动作含义、等待原因和下一步选择。

AI SDK UI 与 LangGraph 的流式消息需要契约适配。ComfyUI 的事件也不能直接当成完整的应用业务状态。

## 设计问题
图片部分生成成功时怎样展示？重连后是否重复插入卡片？用户能否明确看出当前修改的是哪张图？

## 学完的验收
用户无需理解节点、token 或检查点，就能找到当前任务、目标版本与可执行动作；开发者能从同一任务进入检查视图定位问题。
